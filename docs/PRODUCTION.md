# Revisions and production

The Production inspector is the operational production workspace for the active screenplay.

1. Set the production draft label and confirm scene numbers.
2. Lock pages when the draft enters production. Later overflow is labeled with A-pages while anchored pages retain their numbers.
3. Start a colored revision set. SCS saves a protected whole-project baseline automatically.
4. Edit the screenplay, then choose **Update Revision Marks**. Changed text runs receive revision IDs that are preserved in FDX export, and revised pages display the active color.
5. Mark omitted scenes without deleting their text or history.

The same panel generates scene strips, one-line shooting schedules, cast day-out-of-days (SW/W/WF/SWF), revision history, dialogue-only copies, character sides, scene sides, department breakdowns, and portable revision JSON. Scheduling capacity is editable in eighths per day. All generated values are derived from the screenplay and stored production decisions; the reports themselves are not duplicated in the project file.
