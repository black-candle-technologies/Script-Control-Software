# Television workspace

After opening an FDX screenplay, use **Add Episode FDX** to add more linked episode files. SCS displays real episode tabs and maintains each imported document’s scenes, warnings, cast, and locations independently.

The Series inspector aggregates imported character and location names across open episodes. Creating a project wrapper with more than one episode writes a television manifest with a single initial season and episode numbers. Show-bible editing, continuity records, and season arcs remain later work.
