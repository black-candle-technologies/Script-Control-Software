# Television workspace

Create a show from Home or use **Add Episode FDX** / **New Episode** in an existing workspace. Episode tabs keep each script, story structure, notes, entities, reports, and history addressable while sharing project-level television data.

The Series inspector provides:

- editable seasons, season arcs, episode numbers, production codes, cold opens, tags, and act breaks;
- an episode/season board with A/B/C story lines linked to scenes;
- a shared Markdown show bible and show-level character arcs;
- recurring character, location, and object histories with episode references;
- plot-thread history across episodes;
- timeline, character, object, location, plot, and unanswered-question continuity records;
- deterministic checks for missing references, duplicate episode numbers, uncovered or reopened threads, and unresolved continuity.

These values live once in the project workspace. Episode summaries and recurring references are derived from the current screenplay blocks, so edits cannot leave a second aggregate database stale.
