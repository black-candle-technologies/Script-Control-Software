# Next Steps

The roadmap now has a working local-first baseline across writing, development, television, production, versioning, companion, and review workflows.

Further work should be driven by real projects and measured limits:

- Expand FDX fidelity only when fixture or real-file round trips expose loss.
- Add SQLite only when in-memory project search becomes measurably slow.
- Add hosted collaboration only when a deployment, identity, and privacy model is chosen.
- Add in-app Git divergence/rebase tooling only if real teams prefer it to the safer structured shared-folder merge; current Git sync intentionally stops at divergent history.
- Replace print-to-PDF only when browser printing cannot meet a production requirement.
- Add an AI provider only with explicit credentials, consent, and a privacy contract.

These are scale/provider decisions, not missing local workflows. Local roles remain advisory until hosted identity exists, and provider-folder sync depends on the selected provider delivering the file between machines.
